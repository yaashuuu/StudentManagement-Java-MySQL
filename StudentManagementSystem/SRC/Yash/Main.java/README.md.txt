# Student Management System (Java + MySQL)

A simple console-based project using Java, JDBC, and MySQL.

## ✅ Features:
- Add a student and enroll them in courses
- View all enrollments
- View all students
- Search student by name or email

## 💻 Technologies:
- Java
- JDBC
- MySQL
- IntelliJ IDEA

## 🗃️ Database:
- students
- courses
- enrollments

## ⚙️ How to Use:
1. Create the DB using `database.sql`
2. Add your DB credentials in `DBConnection.java`
3. Run `Main.java` and interact with the system!
